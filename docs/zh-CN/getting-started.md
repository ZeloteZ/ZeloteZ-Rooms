# 成员入门

[文档目录](README.md) · [English](../getting-started.md) · [Deutsch](../de/getting-started.md)

本页介绍如何加入已有实例。要部署自己的实例，请阅读[自行托管](self-hosting.md)。

## 准备条件

需要支持 JavaScript 和 Web Crypto 的现代浏览器、可信 Rooms 实例的 HTTPS 地址，以及实例所有者提供的邀请。语音和屏幕共享还需要相应的浏览器与操作系统权限。也可以使用 [Windows 或 Linux 桌面客户端](desktop.md)。

使用 Rooms 或下载公开客户端不需要 GitHub 账户。Rooms 账户属于单个实例，不能自动用于其他服务器。

## 创建账户

1. 打开实例所有者提供的邀请链接。
2. 在登录页选择 **English**、**Deutsch** 或 **简体中文**。
3. 输入显示名称和用户名。新用户名长度为 3–32 个字符，可使用小写字母、数字、下划线、句点和连字符，首字符必须是字母或数字。
4. 设置至少 15 个字符的不常见密码或口令。官方客户端会拒绝常见密码。
5. 点击“创建账户”，并妥善保存用户名和密码。

普通实例地址只提供登录，不开放任意注册。邀请已过期或已使用时，请向所有者索取新邀请。临时房间的访客链接是另一种访问方式，不会创建账户。

密码也保护用于解锁加密聊天的私钥。登录和解锁私钥是相关但独立的过程。详见[安全与隐私](security.md)。

## 登录和解锁聊天

在同一实例地址输入用户名和密码。如果已启用双重验证，按提示输入六位验证器代码或尚未使用的恢复码。

打开新标签页或重新启动客户端后，现有会话可能显示“解锁聊天”。输入密码以在当前环境中解锁聊天密钥。会话已登录，并不意味着所有历史密文已经可以读取。

如果系统提供受保护的凭据存储，桌面客户端可提供“在此设备上保持登录”。它会保存会话和聊天解锁材料，直到会话过期或退出登录。只在可信设备上使用。详见[桌面登录存储](desktop.md#登录存储)。

## 加入第一个房间

1. 打开“房间”，选择对群组可见的房间，或打开私密房间邀请。
2. 点击“加入”或“接受邀请”，成为成员。
3. 进入“聊天”频道并发送消息。
4. 在“朋友”中查找成员并发送好友请求。对方接受后，可通过“消息”或好友条目开始私聊。
5. 在“直播”频道中选择“加入语音聊天”先收听；想发言时再单独启用麦克风。

主页包括收藏、最近访问、动态和正在直播的房间。“群组内所有人”指此实例内已登录的账户，不是向互联网公开。详见[房间与频道](user-guide.md)。

## 个人资料和账户安全

点击名称或头像旁的个人资料，可修改语言、头像、名字颜色、聊天附件加载方式、可选直播通知和视频接收统计，也可以重置首次使用教程。

在“双重验证”中添加验证器，扫描二维码或手动输入密钥，再确认一个代码。请保存仅在该步骤展示的恢复码，并与验证器设备分开存放；每个恢复码只能使用一次。可在同一页面替换验证器或恢复码。普通成员可自行选择是否启用，实例所有者必须启用。

仍记得原密码时，使用“修改密码”。正常修改会保留聊天密钥并结束其他会话。长度和常见密码列表由官方客户端检查；服务器收到的是派生登录凭据，而非原始密码。

## 无法访问账户时

- **丢失验证器：** 使用尚未使用的恢复码。如果恢复码也用尽，请联系所有者；没有通过电子邮件重置验证器的服务。
- **忘记密码：** 没有普通的电子邮件自助重置流程。联系实例所有者，但不要假定所有者能恢复你的聊天私钥或解密历史记录。
- **所有者账户：** [管理指南](administration.md)说明控制台账户恢复和所有者验证器替换。即使恢复账户访问，缺少原聊天密码时，旧聊天仍可能保持锁定。
- **加入后缺少历史记录：** 让有权限的成员保持浏览器登录并解锁聊天，以便分享所需历史消息密钥的加密副本。服务器自己不能提供这些私钥。

连接、媒体或客户端错误请参阅[故障排查](troubleshooting.md)。
