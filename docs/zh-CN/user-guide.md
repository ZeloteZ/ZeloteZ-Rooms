# 房间、聊天和朋友

[文档目录](README.md) · [English](../user-guide.md) · [Deutsch](../de/user-guide.md)

没有账户时，请先阅读[成员入门](getting-started.md)。本页说明持久房间；[临时房间与媒体](streaming.md)使用不同的访问和保留规则。

## 浏览实例

“房间”列出你能看到的房间、邀请、收藏、近期动态和正在直播的房间。加入后即可打开频道；把常用房间标为收藏，方便再次访问。“朋友”包含已确认好友、收到和发出的请求，以及成员搜索。“消息”列出私聊。通知铃铛收集好友请求、私聊和个人提及；已加入房间的直播提醒可在个人资料中自行开启。

首次使用教程说明主要界面，可在个人资料中重置。登录页和个人资料支持英语、德语和简体中文。

## 可见性与成员关系

创建房间时选择访问方式：

| 可见性 | 谁可以加入 |
| --- | --- |
| 群组内所有人 | 此实例上已登录的账户 |
| 私密，仅限邀请 | 被邀请到该房间的账户 |

房间创建者可以逐个邀请已确认好友加入私密房间。受邀者接受后才成为成员。GitHub 仓库公开与否不改变这些应用内权限。

非创建者可选择“离开”。创建者管理房间，而不使用这一离开操作。移除成员或删除房间，不能删除成员已经下载的副本。

## 角色与权限

| 角色或权限 | 主要功能 |
| --- | --- |
| 实例所有者 | 创建账户邀请，管理账户停用和会话；不同于某个房间的创建者。 |
| 房间创建者 | 修改房间名称、可见性、直播规则；管理成员、管理员和设计授权；管理频道、审核消息，并删除整个房间。 |
| 房间管理员 | 管理本房间频道并审核消息。 |
| 单独授予的设计权限 | 修改封面、横幅、背景和颜色。创建者具有此权限；管理员身份本身不自动授予设计权限。 |
| 房间成员 | 阅读和发送可访问的聊天，加入语音，并在房间及频道规则允许时分享媒体。 |

创建者可在“成员”中授予或撤销管理员和设计权限。房间直播规则可允许全部成员、仅允许创建者和管理员，或禁用直播。直播频道另有全部成员/管理员规则，但不能突破房间级限制。

## 频道

“聊天”频道保留文本与附件历史。“直播”频道结合语音、屏幕直播、观影派对和加密频道聊天；直播间隙仍可使用该聊天。

创建者和管理员可以新增、重命名、排序和删除频道。频道类型在创建时选择。删除聊天频道会移除其消息和附件；删除直播频道还会结束活动媒体并删除该频道的直播聊天。删除整个房间会移除所有频道和内容，并结束活动媒体。界面会要求确认这些操作。

## 消息与文件

持久聊天中的一条消息最多 **4,000 个字符**，并可附加**四个文件，每个最多 12 MiB**。在输入区选择文件，移除误选项目，再发送。浏览器会在上传前加密消息和文件内容。

附件名称与内容、分享链接、表情回应和管理理由均加密。成员关系、发送者、时间戳、文件大小及其他运行元数据仍对服务器可见。详见[隐私模型](security.md)。

附件通常在滚动进入视野时加载。个人资料可改为手动加载，或仅自动加载小于指定大小的附件。这控制下载和显示，不改变上传上限。支持的图像、音频和视频可直接预览，其他类型仍可下载；图像可打开较大视图。

账户或实例存储已满、请求配额已用尽时，小于单文件上限的上传也可能被拒绝。详见[限制和配置](configuration.md)。

## 回应、提及和引用

- 使用回应按钮添加或移除自己的表情回应。
- 输入 **@** 可看到人员、房间和频道建议；列表会考虑可访问的目标。链接不会赋予私密房间访问权。
- 使用回复/引用操作引用消息。原消息仍对你的账户可用时，可跳转到它。
- 较长消息可以按需展开。

个人提及可产生通知。为了投递通知，Rooms 需要知道相关账户引用，即使消息正文保持加密。

## 删除和审核消息

你可以删除自己的消息。房间创建者和管理员可以填写理由后删除他人的消息，也可以在同一房间的文本频道间移动消息。理由会为有权接收的人加密。授权审核者还可从聊天中移除删除通知。

删除会移除应用中存储的消息及附件，但无法收回他人已制作的截图、导出或下载副本。移动消息不会让无法访问目标频道的人获得新权限。

## 好友与私聊

通过“朋友 → 搜索”查找账户、发送请求，并在接收方账户接受。确认的好友可打开私聊并分享文字、链接和文件。收到和发出的请求分别展示。

私聊使用相同的消息和附件加密模型。发送需要有效的已确认好友关系；移除好友不会把旧对话变成公开房间。对方账户被停用或好友关系不再有效时，不能继续发送。

## 外观与个人偏好

头像和房间图片接受 **8 MiB** 以内的 JPEG、PNG 或 WebP，也提供内置图片预设。个人资料可设置头像和名字颜色。获得设计权限的成员可调整房间封面、横幅、聊天背景和颜色。

头像与房间外观图片由服务器处理，不像聊天附件那样加密。附件自动加载、直播通知和视频接收统计是个人账户设置。视频接收统计默认关闭；详见[媒体统计](streaming.md#理解统计数据)。

## 历史记录和权限变化

加入房间后，浏览器可以从有权限、已登录并解锁聊天的成员浏览器获取旧消息密钥的加密副本。如果这些浏览器都离线，历史记录可能要等其中一个返回后才可读。请保管自己的密码和密钥；邀请别人或恢复账户访问，不能重新生成已经丢失的私钥。

持久聊天、临时聊天和媒体的具体信任边界及保留差异，请阅读[安全与隐私](security.md)。

## ZeloteZ Vault

运营者可在**管理 → ZeloteZ Vault**中启用私有加密存储和文件共享，默认**每账户 2 GiB**。管理、共享、文件管理器集成、隐私和恢复说明见 [Vault 指南](vault.md)。
