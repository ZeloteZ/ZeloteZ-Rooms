## 实例所有者与房间管理员

**实例所有者**控制邀请与账户访问。**房间创建者**管理该房间的设置、成员、管理员角色和外观授权。**房间创建者与管理员**可以管理频道并审核消息，但管理员角色本身不授予成员管理或外观修改权限。提升某个成员的房间权限不会使其成为实例所有者。账户停用界面无法停用所有者自身的账户。

参照[自行托管](self-hosting.md)，通过单镜像设置向导创建首个所有者账户。注册后，首次设置会永久关闭，不能用于重置密码。后来重新配置相同设置密钥也不会重新开放注册。

## 邀请成员

1. 使用所有者账户登录并打开“邀请”。
2. 在提示时使用当前身份验证器验证码确认敏感操作。
3. 创建邀请，私下分享完整链接。每个邀请允许注册一次，并在所选期限后失效。
4. 邀请发送给错误的人或已不再需要时，应撤销尚未使用的邀请。

界面提供 1 小时、24 小时、3 天和 7 天；API 接受 1–168 小时，未指定时默认 48 小时。邀请令牌位于 URL 片段，服务器只保存哈希。完整秘密链接仅在创建时返回，邀请列表显示状态而不能重新生成该秘密。撤销邀请不会删除已使用邀请注册的账户。

成员注册需要邀请。房间成员资格和访客观看链接是独立权限：邀请他人注册不会自动授予所有受限房间的访问权。参见[用户指南](user-guide.md)和[直播与共享](streaming.md)。

## 账户访问与会话

打开“邀请 → 账户”，可停用/重新启用成员账户，或结束其会话。停用账户会撤销会话与直播。结束会话会要求重新登录，但不会删除账户或已保存消息。此界面无法停用所有者账户。

敏感的所有者操作需要最近的身份验证器确认，有效期为五分钟。MFA 恢复码可以恢复普通登录，但敏感的所有者变更仍需当前身份验证器验证码。能够打开管理页面并不代表永久获准执行所有敏感操作。

## 密码与聊天密钥

成员在“个人资料 → 修改密码”中改密。官方客户端要求至少 15 个字符，并检查本地常见密码列表；已有密码仍可使用。服务器收到派生登录凭据并检查格式，长度和弱密码检查由官方客户端完成。

成功改密会重新包装同一个聊天身份，并结束其他会话。记住登录或恢复账户访问，不能代替用于解锁旧聊天身份的密码。以下所有者工具仅恢复所有者账户；目前没有文档化的通用成员密码重置命令。

## 双因素登录

所有者必须配置身份验证器。其他成员可在“个人资料 → 双因素登录”中启用。扫描二维码并确认六位验证码，将显示的一次性恢复码与身份验证器设备分开保管。个人资料支持更换设备和重新生成恢复码；成员可关闭自愿启用的 MFA，但所有者 MFA 为强制要求。

Docker 主机的时钟应保持同步，因为验证码基于时间。不要在问题报告或截图中公开终端配置输出、二维码或恢复码。

## 替换遗失的所有者身份验证器

使用与运行实例相同的 Compose 文件、项目、`.env` 和数据卷。单镜像方案在仓库根目录运行：

```sh
docker compose --project-directory . --env-file .env -f deploy/compose.image.yaml exec -T rooms node bootstrap.mjs --setup-owner-mfa
```

此命令替换所有者身份验证器，并撤销所有已有的所有者会话。扫描终端二维码，或将输出的密钥手动设为六位、30 秒周期的时间型验证码。重新登录后，在个人资料中生成新的恢复码。拥有此权限的 SSH/Docker 管理员可以接管所有者账户，应相应保护主机访问。

## 恢复所有者账户

当所有者无法登录时，运行：

```sh
docker compose --project-directory . --env-file .env -f deploy/compose.image.yaml exec -T rooms node bootstrap.mjs --recover-owner
```

这会暂停普通所有者登录，撤销现有所有者会话和该所有者创建的未使用邀请，并打印有效期为 **20 分钟**的一次性链接。打开配置的 `PUBLIC_ORIGIN` 上的完整链接，并完成恢复。若过期，请重新运行命令；过期的恢复记录仍会暂停普通所有者登录，直到恢复完成。

如果还记得原聊天密码，请使用它以保留加密聊天访问权。如果遗失密码，可恢复账户访问并让旧聊天身份保持锁定；以后找到密码仍可解锁。恢复操作不会替你解密旧内容。若身份验证器也不可用，还需执行身份验证器替换命令。

不要针对空卷或其他实例的卷运行恢复 CLI；命令必须访问现有实例的数据库。

## 房间管理与删除

房间创建者与管理员可以管理文字/直播频道并审核消息。只有创建者可以修改房间设置和成员、提升或撤销管理员角色、授予或撤销外观权限，以及删除房间。外观访问是单独授权，不会因管理员角色而自动获得。成员可删除自己的消息。移除成员或删除房间会改变应用访问权，但不能抹去接收者已经下载或解密的副本。停用账户、撤销邀请与删除房间或聊天历史是不同操作。

进行会改变账户或房间状态的维护前，应保留可恢复的[备份](operations.md)。API 运行时，切勿直接修改 SQLite 数据库。

## ZeloteZ Vault

运营者可在**管理 → ZeloteZ Vault**中启用私有加密存储和文件共享，默认**每账户 2 GiB**。管理、共享、文件管理器集成、隐私和恢复说明见 [Vault 指南](vault.md)。
