# ZeloteZ Vault

[English](../vault.md) · [Deutsch](../de/vault.md) · [简体中文](vault.md) · [文档](README.md)

Vault 为每位成员提供私有的端到端加密文件存储和只读文件共享。此功能可选，新实例默认关闭。它使用现有账户的加密身份，无需另建云账户。

## 启用与存储限额

运营者打开**管理 → ZeloteZ Vault**，输入身份验证器代码确认所有者权限，启用 Vault 并保存存储限额。默认是**每账户 2 GiB**；限额分别应用于每个账户。

加密文件、加密元数据和未完成上传的预留空间都计入限额。加密会产生少量额外开销。删除文件后，少量技术保护数据仍可能占用空间。降低限额不会删除已有文件；超限账户仍能下载和删除，但不能继续增加存储占用。

关闭 Vault 会阻止上传、下载及两种共享方式。完整文件会保留，直到再次启用；未完成上传会被丢弃。运营者应为所有账户准备足够的磁盘空间，并将应用数据卷纳入[备份](operations.md)。

## 管理文件

1. 在 Rooms 概览右侧**正在直播**下方打开 **ZeloteZ Vault**。只有启用此功能时才显示入口。
2. 创建文件夹，选择**上传文件**，或将文件拖入文件管理器。多个文件依次上传。
3. 在项目菜单中下载、重命名、移动、共享或删除。只能共享文件；文件夹用于整理个人存储。
4. 使用路径导航、搜索、排序和**与我共享**查找文件。

传输显示进度并可取消。请保持 Vault 页面打开直到完成；离开页面或退出账户会取消正在进行的操作。未完成上传不能下载，取消后或清理过期上传时会释放预留空间。删除文件夹也会删除其中内容及其共享。删除无法撤销。

下载在你的设备上解密并保存为普通文件。支持保存文件选择器的浏览器可以分块保存大文件。其他浏览器支持**单文件不超过 128 MiB**的下载。更大文件请使用兼容的 Chromium 浏览器。个人文件和成员共享也可通过桌面客户端保存；公开链接会在浏览器中打开。文件仅下载，不会作为活动网页内容执行或展示。

## 共享文件

在文件菜单选择**共享**并设置有效期：

- **成员：**搜索有效的 Rooms 成员并选择正确账户。接收者可在**与我共享**中找到文件，需要自己的账户加密密钥才能打开。
- **链接：**为没有 Rooms 账户的人员创建链接。请私下发送完整链接。`#` 后的部分包含访问凭据和解密密钥；解密密钥不会发送至服务器。接收页面打开链接后会从地址栏中移除这些秘密。

应像保护文件本身一样保护完整链接。持有链接的人可在过期或撤销前下载和转发文件。共享列表可再次显示已有链接，其保存副本已为你的账户加密。

在共享列表选择**撤销**可终止访问。删除原文件也会终止其共享。撤销、过期或停用发送者账户会阻止后续通过 Rooms 访问，但不能收回接收者已经获得的副本或密钥。文件重命名后，已有共享仍保留创建时的加密名称。

## 可选的文件管理器右键菜单

在 Windows 或 Linux 桌面应用的 Vault 中打开**文件管理器集成**区域。安装和移除均需点击相应按钮并通过原生确认窗口。单独使用浏览器不能安装操作系统右键菜单。

菜单项名为 **Share securely via Vault**。支持 Windows 资源管理器；Linux 会自动检测 **Files/Nautilus、Nemo、Caja、Dolphin 和 Thunar**。GNOME Files 和 Caja 将项目放在**脚本**子菜单中；Windows 11 可能将其放在**显示更多选项**中。如菜单未刷新，请重新打开文件管理器窗口。

选择本地文件或文件夹并点击该菜单项。Rooms 会打开 Vault，显示目标实例和所选内容供确认，在本地生成 ZIP，并在上传前分块加密。磁盘上不会写入未加密的临时 ZIP；原始文件保持不变。上传后会打开共享对话框，由你选择接收者或创建链接。

文件夹包含其普通内容，包括隐藏文件。符号链接和特殊文件会被拒绝；文件发生更改、归档路径不安全或所选内容超过限制时会中止。完成之前请勿更改所选文件。

选择**移除集成**即可删除受管理的菜单项；其他自定义操作会保留。Linux AppImage 应保存在长期使用的位置。移动它或更新到不同路径后，请重新安装集成以更新启动命令。

## 隐私与恢复

内容、文件名、文件夹名和文件类型在上传前加密。服务器仍可看到账户归属、大小、时间、文件夹关系和共享关系。共享为只读，不授予接收者访问你其余 Vault 内容的权限。

正常更改密码会保留文件访问权。不提供原加密密码的账户恢复无法解密已有 Vault 文件；运营者没有你的账户密钥便无法恢复内容。重要数据请保留独立副本。

请使用可信的实例和设备。与加密 Rooms 聊天一样，实例提供应用界面；被篡改的客户端代码或受入侵的设备可能削弱端点保护。详情见[安全与隐私](security.md)。
