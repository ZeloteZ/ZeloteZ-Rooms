# ZeloteZ Vault

[English](../vault.md) · [Deutsch](../de/vault.md) · [简体中文](vault.md) · [文档](README.md)

Vault 为每位成员提供私有的端到端加密文件存储和只读文件共享。此功能可选，新实例默认关闭。它使用现有账户的加密身份，无需另建云账户。

## 启用与存储限额

运营者打开**管理 → ZeloteZ Vault**，输入身份验证器代码确认所有者权限，启用 Vault 并保存存储限额。默认是**每账户 2 GiB**；限额分别应用于每个账户。

加密文件、加密元数据和未完成上传的预留空间都计入限额。加密会产生少量额外开销。删除文件后，少量技术保护数据仍可能占用空间。降低限额不会删除已有文件；超限账户仍能下载和删除，但不能继续增加存储占用。

关闭 Vault 会阻止上传、下载及两种共享方式。完整文件会保留，直到再次启用；未完成上传会被丢弃。运营者应为所有账户准备足够的磁盘空间，并将应用数据卷纳入[备份](operations.md)。

## 管理文件

1. 在 Rooms 概览右侧**正在直播**下方打开 **ZeloteZ Vault**。只有启用此功能时才显示入口。
2. 第一列**文件**包含你的个人文件、文件夹以及**与我分享**文件夹。打开**与我分享 → 发送者用户名**，即可浏览该成员提供的只读分享。
3. 打开文件夹后，其内容显示在下一列。根目录列与最多两列子文件夹可以同时显示。窗口较窄时，会自动减少可见的文件夹列数，不会出现水平滚动条。进入更深层级时会重复使用最右侧一列。横幅中的路径仍保留完整层级；点击上级文件夹即可返回，或通过 **…** 打开被折叠的上级路径。
4. 点击文件所在行，在文件夹旁打开预览、播放器或编辑工具。浏览其他文件夹时，预览会保持打开。点击预览中的 **×** 即可关闭文件。
5. 右键点击一行或点击其 **⋯** 按钮，可使用**打开**、**下载**、重命名、移动、分享和删除等操作。也可使用键盘菜单键或 **Shift+F10** 打开菜单。可用操作取决于项目类型；收到的分享不能修改发送者的原文件。
6. 创建文件夹，选择**上传文件**，或将本地文件拖入自己的文件夹。多个文件依次上传。要移动自己的 Vault 文件或文件夹，可将其拖到另一个个人文件夹或路径中的根目录，也可在项目菜单选择**移动**。文件夹不能移动到自身或自己的子文件夹中。**与我分享**及其中的发送者文件夹均为只读位置。只能分享文件；文件夹用于整理个人存储。
7. 搜索和排序当前文件夹。长列表在各自的列内滚动，预览也有独立的滚动区域；横幅和整个页面保持固定，无需切换上一页或下一页。

正在进行的传输以紧凑通知显示进度，并可直接取消。传输完成或取消后会显示通知，不会留下长期占用空间的历史面板。请保持 Vault 页面打开直到完成；离开页面或退出账户会取消正在进行的操作。未完成上传不能下载，取消后或清理过期上传时会释放预留空间。删除文件夹也会删除其中内容及其分享。删除无法撤销。

点击齿轮按钮 **Vault 设置**，查看隐私说明并配置桌面应用的可选文件管理器集成。

## 在本地打开、播放与编辑

点击文件所在行，或在项目菜单选择**打开**。播放器或编辑工具会显示在独立预览区域。文件会在你的设备上验证并解密；预览和编辑不会将明文发送到服务器或外部编辑服务。HTML、SVG 和源代码始终作为纯文本处理，绝不会在编辑器中执行。公开分享链接仍提供下载；这些编辑工具位于已登录用户的 Vault 内。

| 文件类型 | 可用工具 | 本地限制 |
| --- | --- | --- |
| 图片，包括 PNG、JPEG、WebP、GIF、BMP、AVIF 和通过验证的 ICO 图标 | 裁剪边缘、旋转、水平或垂直翻转；导出为 PNG、JPEG 或 WebP | 源文件最大 10 GiB，解码后最多 33,554,432 像素 |
| 视频与音频，包括受支持的 MKV 文件 | 带播放控件的本地播放器 | 源文件最大 10 GiB；可用编解码器取决于浏览器和操作系统 |
| PDF | 逐页预览、调整页序、旋转、删除页面、放置文字批注 | 源文件最大 64 MiB，最多 500 页；至少保留一页 |
| 文本、Markdown、JSON、CSV、配置文件和常见源代码 | 编辑 UTF-8 或带 BOM 的 UTF-16 文本、切换自动换行、查看行数与字符数；保存 JSON 前会检查语法 | 包括编码和 BOM 在内，最大 2 MiB |
| DOCX 文档和 XLSX 工作簿 | 编辑段落、表格和单元格；保存简化的 DOCX 或 XLSX 副本 | 源文件最大 32 MiB；总计最多 2 MiB 文本、20,000 个单元格、2,000 行、每行 64 列、20 个工作表 |
| ZIP、TAR、TAR.GZ 和 TGZ 压缩包 | 浏览文件夹、在本地打开受支持的成员文件、单独下载，或保存为新的加密 Vault 文件 | 源文件最大 64 MiB、解压后内容最多 128 MiB、最多 2,000 个条目；单个解压文件最大 32 MiB |

媒体支持单个源文件最大 **10 GiB（10,737,418,240 字节）**，同时须在你的 Vault 存储额度内。文件在打开前分块验证并解密，大文件需要较长的准备时间。浏览器管理解密后的本地数据，并可能使用设备上的临时文件，因此需要足够的本地存储空间和浏览器配额；设备及解码器也可能限制可用性。关闭预览会释放相关引用，但无法保证安全擦除浏览器临时存储。服务器不会收到明文或解密密钥。图片尺寸会在解码前检查，独立的像素上限仍然适用。

生成第一帧时最多读取 **512 MiB 的编码图片数据**。如果第一帧就需要更多数据，便无法在本地打开。如果浏览器不支持对该图片格式进行流式解码，备用加载方式仅支持最大 **128 MiB** 的图片。文件大小与解码后的像素数是独立限制；10 GiB 的输入上限不保证每张图片都能在每台设备上解码。

导出的图片是静态图片，会移除源图片的元数据；动画图片也会变为静态图片。编辑后导出的副本最大为 128 MiB。

音频和视频在本地播放器中打开，不在 Vault 中编辑或导出。如果浏览器和操作系统提供所需编解码器，MKV 可播放 H.264/AAC、VP9/Opus 等组合。仅有 MKV 扩展名并不保证可以播放。对于不受支持的编解码器或超过播放器大小上限的文件，请下载原文件并使用合适的本地应用打开。

对于受支持的 MKV 和 MP4 文件，如果包含多个音轨或内嵌字幕，会显示**音频**和**字幕**选项。选择原始音轨（默认）可以恢复文件最初的音频选择；选择关闭可以停用字幕。MKV 内嵌的 SRT、简单 ASS 文本以及 MP4 的 `mov_text` 字幕可以作为被动文本字幕显示，ASS 排版和样式不会保留。PGS 等图形字幕不受支持，相应选项会被禁用；请下载原文件并用合适的本地播放器打开。音轨和字幕均来自本地解密的文件，不会联系外部字幕服务。你的选择仅作用于当前设备，在房间内播放 Vault 文件时也是如此：每位观众独立选择，不会改变房间的共同播放状态或其他观众的语言选择。

音轨与字幕分析还有独立的安全限制：最多 **64 个轨道**、**16 MiB 元数据**，每次分析最多在本地读取 **32 MiB 文件数据**。文本字幕最多包含 **20,000 条字幕及 2 MiB 文本**。MKV 字幕文本会在选择相应轨道时读取。超过这些限制时，部分字幕或自定义轨道选择可能不可用，但普通播放仍可能正常。此时请使用原始音轨，或下载文件并用合适的本地播放器打开。

文本副本会保留检测到的 UTF-8 或 UTF-16 LE/BE 编码、BOM 和换行风格。自动识别 UTF-16 需要文件带有 BOM。无效 Unicode 和二进制数据会被拒绝；其他文本编码需要先用合适的本地应用转换。

Office 编辑会创建简化副本，包含文档的段落与表格，或工作簿的单元格。复杂排版、图片、图表和嵌入对象不会保留。公式作为文本显示和保存，不会计算；宏和外部数据连接不会运行。如果需要这些功能或精确保留排版，请在合适的 Office 应用中使用原文件。单元格、行数和文本限制适用于整个文档或工作簿。Office 内容解压后还受到 16 MiB 总量和单个 XML 文件 4 MiB 的限制。

在压缩包中选择文件，然后点击**打开所选文件**、**下载所选文件**或**保存到 Vault**。打开成员文件仅在本地进行。点击**返回压缩包**，即可从文件预览返回压缩包内容。**保存到 Vault**会以成员文件的名称创建一个全新加密文件，放在原压缩包所在的 Vault 文件夹中。对于收到的成员分享压缩包，副本保存在**文件**根目录。压缩包内的文件夹用于浏览，不会作为文件夹树导入 Vault。原压缩包和已有分享保持不变。大文件仍会列出，但超过 32 MiB 时无法在本地打开、解压或单独下载；请改用**下载原压缩包**。解压内容上限也限制每次打开期间实际解压的数据量。ZIP64、加密 ZIP、符号链接、硬链接和不受支持的压缩方法需要在合适的本地应用中处理。不安全或损坏的压缩包会被拒绝。

PDF 预览仅呈现静态内容。保存的 PDF 副本会移除交互链接、表单、附件和嵌入脚本。新增批注会以图片图层嵌入，因此其中的文字无法选中。原有页面内容会保留；这些工具用于页面管理与批注，不是完整的文档排版编辑器。受密码保护或不受支持的 PDF 可能无法打开。

编辑图片、PDF、文本或受支持的 Office 文件后，选择副本名称并点击**保存加密副本**。每次保存都会上传使用全新加密的新文件，原文件及已有分享保持不变。个人文件的编辑副本保存在原文件夹中；成员分享的编辑副本保存在**文件**根目录，归你所有，不会修改发送者的文件。保存额外副本需要足够的剩余 Vault 空间；如需分享新副本，请单独创建分享。

未保存的更改仅存在于当前编辑器中。切换文件、关闭编辑器或离开 Vault 时，都会询问是否丢弃这些更改。退出登录或会话结束会立即取消操作并丢弃本地更改，不提供自动草稿恢复。

其他格式仍可存储、分享或下载到合适的本地应用中使用。DOCX 和 XLSX 之外的 Office 格式，例如 PPTX、ODT、ODS 以及旧版 DOC、XLS，没有内置编辑工具。

## 下载文件

下载在你的设备上解密并保存为普通文件。支持保存文件选择器的浏览器可以分块保存大文件；其他浏览器支持**单文件不超过 128 MiB**的下载。更大文件请使用兼容的 Chromium 浏览器。个人文件和成员分享也可通过桌面客户端保存；公开链接会在浏览器中打开。下载的文件不会自动打开。上面的编辑限制不会限制账户存储限额内的普通上传和受支持的分块下载。

## 在房间中共同播放

为个人 Vault 中的音频或视频选择文件菜单或播放器中的**在房间中播放**。支持最大 **10 GiB** 的文件。选择已加入的房间及其中一个直播频道；你的账户须有权在该频道发起播放。

- 没有活动中的观影派对时，选择**在此共同播放**，准备同步播放。
- 已有活动中的观影派对时，选择**添加到播放队列**，在当前项目之后播放你的文件。

确认后会创建一项单独、可撤销的 **24 小时加密分享**。访问凭据和解密密钥会为分享时有权访问该频道的成员加密，不会放入聊天消息或房间导航地址。服务器保存加密内容与加密播放信息，不会收到文件解密密钥。

确认后点击**前往房间**，即可打开所选频道和观影派对。在你主动跳转之前，本地播放器保持不变。成员使用房间的同步播放控件，可能需要先在自己的设备上允许播放。可用编解码器取决于各自的浏览器。

原文件保留在 Vault 中。结束观影派对或离开房间**不会自动撤销**此分享。需要时请在原文件的**分享 → 有效分享**列表中撤销；否则分享会在 24 小时后过期。与其他分享一样，已经取得的副本和密钥无法收回；房间成员资格变化也不会收回已经获得的访问凭据。

收到的成员分享不能直接转发到房间。请先在**文件**中放入自己的文件，例如下载后重新上传自己的副本。发起房间播放需要明确确认；仅打开私密播放器不会分享文件。

## 分享文件

在文件菜单选择**分享**并设置有效期：

- **成员：**搜索有效的 Rooms 成员并选择正确账户。接收者可在**与我分享 → 发送者用户名**中找到文件，需要自己的账户加密密钥才能打开。
- **链接：**为没有 Rooms 账户的人员创建链接。请私下发送完整链接。`#` 后的部分包含访问凭据和解密密钥；解密密钥不会发送至服务器。接收页面打开链接后会从地址栏中移除这些秘密。

应像保护文件本身一样保护完整链接。持有链接的人可在过期或撤销前下载和转发文件。分享列表可再次显示已有链接，其保存副本已为你的账户加密。

在共享列表选择**撤销**可终止访问。删除原文件也会终止其共享。撤销、过期或停用发送者账户会阻止后续通过 Rooms 访问，但不能收回接收者已经获得的副本或密钥。文件重命名后，已有共享仍保留创建时的加密名称。

## 可选的文件管理器右键菜单

在 Windows 或 Linux 桌面应用的 Vault 中点击齿轮按钮，打开 **Vault 设置 → 文件管理器集成**。安装和移除均需点击相应按钮并通过原生确认窗口。单独使用浏览器不能安装操作系统右键菜单。

菜单项名为 **Share securely via Vault**。支持 Windows 资源管理器；Linux 会自动检测 **Files/Nautilus、Nemo、Caja、Dolphin 和 Thunar**。Nautilus 和 Caja 会将此操作直接放在所选文件的右键菜单中。Windows 11 可能将其放在**显示更多选项**中。

Nautilus 和 Caja 需要各自的 Python 扩展支持，即 `nautilus-python` 或 `python-caja`；实际软件包名称可能因发行版而异。如果缺少支持，Vault 会显示所需组件。安装发行版提供的对应软件包后，请重新启动 Rooms 和文件管理器。

如果旧版 Rooms 在**脚本**子菜单中安装了受管理的项目，请选择**更新右键菜单**。此操作会安装直接菜单项，并移除原来受管理的脚本。其他脚本、扩展和自定义操作会保留。

安装、更新或移除集成后，请**完全重新启动 Linux 文件管理器**。仅打开另一个窗口可能不会加载或移除右键菜单扩展。

选择一个或多个本地文件或文件夹并点击该菜单项。Rooms 会打开 Vault，并让你一次确认目标实例和全部所选内容。每个文件直接以原名上传，每个文件夹分别生成为一个**文件夹名.zip**；混合选择时，每个文件和文件夹都会对应一个独立的 Vault 项目。所有项目均在设备上分块加密后上传。文件夹 ZIP 以流式方式处理，不会在磁盘上写入未加密的临时 ZIP。原始文件保持不变。

仅上传一个项目后，可在分享对话框中选择接收者或创建链接。如果仍有其他对话框打开，或上传了多个项目，通知会提示你通过各自的文件菜单进行分享。每个项目都可以单独分享。取消或后续发生错误时，剩余上传会停止；已成功上传的项目仍会保留在 Vault 中。旧版桌面应用需要更新才能使用此选择上传方式。

文件夹包含其普通内容，包括隐藏文件。符号链接和特殊文件会被拒绝；文件发生更改、归档路径不安全或所选内容超过限制时会中止。完成之前请勿更改所选文件。

选择**移除右键菜单**即可删除受管理的菜单项。Linux AppImage 应保存在长期使用的位置。移动它或更新到不同路径后，请打开新的 AppImage，选择**更新右键菜单**以更新启动命令，然后重新启动文件管理器。

## 隐私与恢复

内容、文件名、文件夹名和文件类型在上传前加密。服务器仍可看到账户归属、大小、时间、文件夹关系和共享关系。共享为只读，不授予接收者访问你其余 Vault 内容的权限。

正常更改密码会保留文件访问权。不提供原加密密码的账户恢复无法解密已有 Vault 文件；运营者没有你的账户密钥便无法恢复内容。重要数据请保留独立副本。

请使用可信的实例和设备。与加密 Rooms 聊天一样，实例提供应用界面；被篡改的客户端代码或受入侵的设备可能削弱端点保护。详情见[安全与隐私](security.md)。
